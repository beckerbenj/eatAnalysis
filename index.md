# eatAnalysis

## Overview

`eatAnalysis` provides helpful functions for educational research. This
includes functions for processing `lme4` output, writing files to
`.xlsx` and calculating (weighted) descriptive statistics.

## Installation

``` r

# Install eatAnalysis from GitHub via
devtools::install_github("beckerbenj/eatAnalysis")
```

## Usage

``` r

library(eatAnalysis)
```
