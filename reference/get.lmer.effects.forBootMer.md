# `get.lmer.effects` for bootstrap

This is a wrapper for the
[`get.lmer.effects`](https://beckerbenj.github.io/eatAnalysis/reference/get.lmer.effects.md)
only intended to prepare bootstrap analyses. See examples of
[`get.lmer.effects`](https://beckerbenj.github.io/eatAnalysis/reference/get.lmer.effects.md)
for further details.

## Usage

``` r
get.lmer.effects.forBootMer(lmerObj)
```

## Arguments

- lmerObj:

  An object of class `merMod` or `glmerMod`, as created by
  [`lmer`](https://rdrr.io/pkg/lme4/man/lmer.html) or
  [`glmer`](https://rdrr.io/pkg/lme4/man/glmer.html) from the `lme4`
  package.

## Value

A numerical vector of values.
